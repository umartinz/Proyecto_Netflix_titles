# Proyecto para Netflix

Proyecto de Analisis de datos con peliculas y series de Netflix

Este repositorio contiene el análisis realizado durante el proyecto del caso Netflix.

El dataset `Netflix_titles.csv` contiene información de titulos, pais, descripcion

## 📂 Contenido del repositorio

- `Proyecto_Rappiplus.ipynb`
  → Notebook principal con limpieza, visualizacion, tasas, pruebas e Insight ejecutivo.

## ▶ Cómo abrir el notebook en Google Colab

1. Abre el archivo `.ipynb` en GitHub
2. Haz clic en **Open in Colab**

## 📘 Cómo reproducir el análisis

1. Abre `Proyecto_Rappiplus.ipynb`
2. Ejecuta las celdas en orden
3. El notebook carga automáticamente el dataset desde `/data/` o desde un enlace público (según corresponda)
